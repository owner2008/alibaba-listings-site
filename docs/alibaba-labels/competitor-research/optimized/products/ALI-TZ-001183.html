Which material and surface finish does this design use?

The proposed configuration uses white BOPP film with printed ivory artwork and a satin surface. A gloss finish can also be discussed during sample development.

Is the gold effect metallic foil or yellow printing ink?

The specified finish is metallic gold hot stamping on selected artwork areas. It is a foil finish rather than ordinary yellow ink and does not imply solid gold content.

Can multiple dessert designs and sizes be planned together?

Yes. Provide one final artwork file and an order quantity for each design. Separate sizes and foil areas are itemized so that a multi design project can be planned consistently.

What label sizes can be customized?

This project includes 50 x 150 mm 70 x 90 mm 60 x 80 mm and 60 x 50 mm examples measured as width x height. Other dimensions can be developed for the actual container.

What files are useful for printing and foil preparation?

Send a vector PDF or AI file with outlined fonts finished dimensions and bleed. Keep the metallic foil artwork on a separate clearly named vector layer or spot color mask.

How should the labels be evaluated for refrigerated packaging?

Test a physical sample on the actual container using the intended application temperature storage conditions and condensation cycle. Review adhesion print durability and foil appearance before approving production.

Do these labels contact food directly?

This listing is for the exterior of closed food packaging. Direct food contact use requires a separate material specification and the relevant supporting documents.

How are samples unit prices setup costs lead time and freight quoted?

Provide the size material finish foil coverage quantity per design supply format and delivery postcode. Request separate sample tooling foil production and shipping costs including a DDP option where available.
